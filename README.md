# Arya Shah — Portfolio

A professional portfolio website for Arya Shah, a software engineer based in Vadodara, India, specializing in enterprise financial systems, applied machine learning, and digital experiences.

## Features

- **Hero section** with portrait and introduction
- **About** — engineering philosophy and focus areas
- **Career trajectory** — timeline of roles at MRI Software and Shakti Infotech
- **Selected work** — six projects with live links and GitHub repositories
- **Capabilities & skills** — technical stack overview
- **Contact form** — messages saved securely to Supabase with row-level security
- **Light/dark mode** — theme toggle with consistent color tokens
- **SEO optimized** — structured data (JSON-LD), Open Graph, Twitter Cards, sitemap, robots.txt
- **Fully responsive** — mobile-first design with hamburger navigation

## Tech Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- Lucide React icons
- Supabase (contact form backend with RLS)

## Deploy to Vercel

1. Push this repository to GitHub
2. Import the repo on [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite — no configuration needed
4. Add environment variables in Vercel project settings:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. Deploy
